## 3. Disclosure: synthetic-user pipeline test (2026-08-20)

MaintChain's repository contains a **synthetic-user end-to-end harness** (`scripts/synthetic-users/`) used to validate that the registration and on-chain verification pipeline works at volume before inviting real users. Key facts, stated openly:

- It programmatically generated 50 Testnet wallets (`SYNTH-0001`…`SYNTH-0050`).
- All 50 completed `IdentityRegistry.verify_identity` as real on-chain transactions.
- These accounts are **test artifacts, not users**, and are excluded from every traction number in this submission.
- A bulk batch of Google Form responses submitted on 2026-08-22 reused these same wallets and is likewise **excluded** from user counts and treated only as harness output.
- The earlier plan document (`docs/synthetic-users-audit.md`) is retained in the repository for transparency.

No synthetic account is presented anywhere in this submission as a genuine user.
